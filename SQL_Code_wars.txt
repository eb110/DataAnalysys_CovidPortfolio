orders:

id (integer) - Unique identifier for the order.
customer_id (integer) - Identifier for the customer who placed the order.
order_amount (integer) - The amount of the order.
order_date (date) - The date the order was placed.
Your task is to write an SQL query that calculates the total amount of orders for each customer for September 2023 and determines the corresponding rebate percentage they are eligible for based on their total orders.

Objectives:

Calculate the sum of order amounts for each customer for orders placed in September 2023 (Assuming that the orders table contains various orders with order_date spanning different months and years, and order_amount varying between orders).
Determine the appropriate rebate percentage for each customer based on the calculated total order amount.
Exclude customers who do not have orders in September 2023 or whose total orders in September 2023 are below the lowest min_purchase in the rebates table.
A result set should contain the following columns:

customer_id (integer) - The ID of the customer.
total_orders (integer) - The total sum of the orders made by the customer in September 2023.

and be sorted by customer_id in descending order.

(select rebate_percentage from rebates where sum(ord.order_amount) >= min_purchase
order by rebates desc limit 1) as rebate_percentage
from orders as ord

group by ord.customer_id
having sum(ord.order_amount) >= (select min(min_purchase) from rebates)
order by 1 desc

Cantor pairing function

create or replace function cnt_fc (n bigint)
returns varchar as $$
declare
  m bigint := 0;
  p bigint := 0;
  d bigint := 0;
begin
  m = ceil((sqrt(1 + 8 * n) - 1) / 2);
  p = m * (m + 1) / 2;
  if mod(m, 2) = 0 then d = m - 1 - p + n;
  else d = p - n;
  end if;
  return concat('', (1 + d), '/', (m - d));
end;
$$ language plpgsql;


select n, cnt_fc(n) as res
from cantor

create or replace function boost_f (s int, t int)
returns bigint as $$
declare
  boost int = 0;
begin
  boost = least(s / 3 + 1, (t + 1) / 2);
  return (t + boost) * s - boost * (boost - 1) * 3 / 2;
end;
$$ language plpgsql;

from speedandtime

create or replace function sum_fct (f_max bigint)
returns bigint as $$
declare
  a bigint := 0;
  b bigint := 1;
  res bigint := 0;
begin
      while b < f_max loop
        a = a + b;
        if a < f_max and mod(a, 2) = 0 then res = res + a;
        end if;
        b = b + a;
        if b < f_max and mod(b, 2) = 0 then res = res + b;
        end if;
      end loop;
      return res;
end;
$$ language plpgsql;

You are given a table named orders in a PostgreSQL database, which stores order details for an e-commerce application. order_id is the primary key and product_id represents the product ordered.

A sample set of data is as follows:

| order_id | product_id |
|----------|------------|
|    1     |     8      |
|    2     |     3      |
|    3     |     12     |
|    4     |     8      |
|    5     |     7      |
|    6     |     8      |
|    7     |     3      |
|    8     |     1      |
Your task is to write a PostgreSQL query that retrieves the orders in ascending order by order_id. However, there's a specific ordering condition - if there are multiple orders for the same product (product_id has duplicates), those orders should appear first. Within these groups and the remaining orders, they should be sorted by the smallest order_id of the group and then by order_id.

So thus the expected output of running this query with the provided sample data would be:

| order_id | product_id |
|----------|------------|
|    1     |     8      |
|    4     |     8      |
|    6     |     8      |
|    2     |     3      |
|    7     |     3      |
|    3     |     12     |
|    5     |     7      |
|    8     |     1      |
Let's break this down:

select *,
case when count(*) over (partition by product_id) > 1 then 2
else 1
end as dupa1,
min(order_id) over (partition by product_id) as dupa2
from orders
order by 3 desc, 4, 1
)

details (varchar) - Additional details related to the student (for this challenge, it may have a static value like 'X').
subjects:

subject_id  (varchar) - Unique identifier for each subject (e.g., 'M' for Math).
subject_name (varchar) - Name of the subject (e.g., 'Math', 'English').
marks:

student_id (integer) - Identifier linking to the students table.
subject_id (varchar) - Identifier linking to the subjects table.
mark_rate (integer) - The mark or score the student has received for the subject.

with top_marks as (
select subject_id, max(mark_rate) as top
from marks
group by subject_id)

select array_agg(st.student_name order by st.student_id) as student_names, sbj.subject_name, tm.top as mark_rate
from marks as ms
join top_marks as tm
on ms.subject_id = tm.subject_id
join students as st
on ms.student_id = st.student_id
join subjects as sbj
on ms.subject_id = sbj.subject_id
where ms.mark_rate = tm.top
group by sbj.subject_name, tm.top
